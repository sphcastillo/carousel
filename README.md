# carousel

## Color palette

Tokens live in `src/app/globals.css` and map to Tailwind as `bg-primary`, `text-canvas`, `border-nav`, and so on.

| Token | Hex | Tailwind | Use |
| --- | --- | --- | --- |
| `--primary` | `#A41A28` | `primary` | Burgundy — kickers, buttons, statement accent |
| `--nav` | `#641326` | `nav` | Sticky header bar |
| `--secondary` | `#F5C4D0` | `secondary` | Blush — editorial panel, soft fills |
| `--accent` | `#A8D8E4` | `accent` | Ice blue — statement band, highlights |
| `--canvas` | `#F6EEE6` | `canvas` | Page background, cream type on photos |
| `--ink` | `#2A1216` | `ink` | Body text |
| `--surface` | `#FBF6F0` | `surface` | Cards and framed photos |

Hero overlay (not a token): `rgba(55, 7, 16, 0.61)` at the left, fading to `rgba(55, 7, 16, 0.04)` through the center, then `rgba(30, 3, 7, 0.22)` on the right.
